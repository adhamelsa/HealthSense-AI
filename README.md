# ❤️ HealthSense AI

## Heart Disease Prediction System

HealthSense AI is a Machine Learning-based application designed to predict the risk of heart disease using patient clinical data.

### Technologies

- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Streamlit

### Features

- Heart disease risk prediction
- Machine Learning model
- Interactive web interface
- Easy-to-use patient input system
